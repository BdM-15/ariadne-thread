Shipley PDW — the standard one-page-per-section planning artifact authors complete BEFORE writing prose. Required fields: (1) Section Outline mapped to RFP requirements (e.g., 2.2 Performance → 2.2.1 Flight Control, 2.2.2 Stability), (2) Relevant Proposal/Volume Strategies (which win themes apply), (3) Defining Your Solution → Major Issues (customer pain points being solved), (4) Key Visuals with Action Captions (figure number, title that asserts a benefit, caption explaining the proof). PDWs are the bridge from [[annotated-outline]] to draft text and feed Pink Team review. Per Shipley Proposal Guide model docs (pp. 314-316).
