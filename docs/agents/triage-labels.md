# Triage Labels

Use the default Matt Pocock skill label vocabulary unless the GitHub repository is configured differently later.

| Role | Label |
|------|-------|
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for an AFK agent | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |
